# Third-party Skill Sources

The offline ecosystem catalog contains translated and processed Skill instructions
derived from the following public source collections. Runtime installation never
downloads content from these repositories.

| Source collection | Imported entries | Upstream license | Distribution note |
| --- | ---: | --- | --- |
| [`nexscope-ai/eCommerce-Skills`](https://github.com/nexscope-ai/eCommerce-Skills) | 162 | MIT | Attribution retained in the catalog manifest. |
| [`hikari0511/awesome-amazon-ec-skills`](https://github.com/hikari0511/awesome-amazon-ec-skills) | 32 | CC0-1.0 | Entries are processed instruction snapshots, not installations of linked tools. |
| [`noique/cross-border-ecommerce-skills`](https://github.com/noique/cross-border-ecommerce-skills) | 9 | CC BY-NC 4.0 | Commercial redistribution requires explicit authorization or legal approval before release. |

Every ecosystem catalog entry records `sourceRepository`, `sourcePath`,
`originKind`, `legacyEcosystemId`, and a content hash. The processed snapshots may
differ from upstream wording and do not imply that any external API, MCP server,
script, or credential is bundled or available.
