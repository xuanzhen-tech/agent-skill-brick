# 竞品变化分析方法

## 1. 对象稳定优先

在计算前核对 ASIN、父子体、变体、包装数量和版本。商品换代、合并或拆分后，应建立新序列或清楚标出断点。

### 正例

两个时点都对应同一 marketplace、同一子 ASIN 和相同包装数量，字段定义一致，可比较价格。

### 反例

基线使用父 ASIN 汇总销量，当前使用某个子 ASIN 估算，却直接计算下降率。

## 2. 可比性三态

- **完全可比**：对象、时间、定义、单位和覆盖都匹配；
- **部分可比**：仍可判断方向，但差值会误导；
- **不可比**：关键条件不匹配。

部分可比时明确能比较什么、不能比较什么。

## 3. 常见断点

- 父体与子体变化；
- 币种、税费和 Coupon 口径变化；
- 自然、广告或全流量范围变化；
- 日、周、月粒度混用；
- Top N 或分页变化；
- 供应商算法或字段定义变化；
- 商品改款、包装数量变化；
- 检索时间与活动期不一致。

## 4. 变化计算

绝对变化：

`Δ = current - baseline`

基线非零且可比时，相对变化：

`Δ% = (current - baseline) / baseline × 100%`

排名数值下降通常代表位置改善，但必须确认排名体系。基线为零或字段缺失时，不计算百分比。

## 5. 同步变化的解释

同步发生的价格、Coupon、内容、流量和排名变化，可以形成行动线索，但不能证明竞品策略或动机。用“观察到”“可能相关”“需要进一步验证”，避免“竞品为了……所以……”。

## 6. 多源冲突

先查对象、时间、定义、单位、采样和分页。若仍无法解释，保留各家原值和限制。冲突本身是结论的一部分。
