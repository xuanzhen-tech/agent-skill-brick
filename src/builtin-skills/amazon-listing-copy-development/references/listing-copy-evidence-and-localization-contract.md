# 文案证据与本地化方法

## 一、先划定可写范围

| 事实情况 | 正文处理 |
|---|---|
| 来源明确、适用变体和条件清楚 | 可以准确重述 |
| 可由直接事实合理解释，但有适用条件 | 可以谨慎表达并保留条件 |
| 用户明确提供但未独立核验 | 可按用户提供内容处理，同时标明来源和待核事项 |
| 含义、单位、变体或条件不清 | 不进入正式文案 |
| 无证、误导、敏感或明确禁止 | 删除 |

评论、关键词、竞品表达或供应商流量字段可以帮助选择沟通主题，但不能单独证明产品性能。

## 二、事实性句子如何留痕

每个事实性句子或短语至少说明：

- 所在字段和最终目标语言文本；
- 支撑它的产品事实、适用变体和原始位置；
- 使用了哪些关键词以及为什么适合该字段；
- 是直接事实、带条件的利益表达，还是用户提供但待核的内容；
- 是否存在合规、单位、比较、绝对化或歧义风险；
- 是否需要人工复核，以及缺少什么。

无需给每句话制造通用记录编号。能够从“文案位置 → 产品事实/关键词 → 来源原文或结果位置”直接追溯即可。Agent 改写、压缩和本地化后的文案不能冒充来源原文。

## 三、安全表达

- 用精确事实替代空泛“高品质”；
- 利益表述必须能从事实合理解释，并保留使用条件；
- 对“最强、第一、永久、零风险、保证结果”等绝对化语言要求直接证据和当前适用规则，否则删除；
- 比较性表述必须说明比较对象、指标、期间和证据；
- 认证、医疗、安全、环保和法律宣称需要明确文件及适用范围；
- 评论痛点可以帮助选择沟通主题，不能证明产品已经解决该问题。

## 四、多语言质量门

对源语言与目标语言逐项核对：

1. 产品身份是否一致；
2. 数字、单位、时间、数量和兼容型号是否一致；
3. 条件、否定、例外和适用范围是否保留；
4. 事实是否被目标语言夸大或弱化；
5. 关键词变形是否保持原意和自然表达；
6. 品牌语气是否一致；
7. 是否出现目标市场可能误解的缩写、量制或含糊代词；
8. 高风险句子是否已安排人工审核。

“读起来流畅”不能替代含义一致性。

## 五、版本差异

需要多个版本时，每个版本只改变一个主要表达角度，例如信息顺序、利益主题、关键词自然变体或品牌语气。不得同时改变产品事实、价格、促销、适用范围和多个卖点，再声称可以判断哪个因素有效。
