# 竞品促销响应方法

## 1. 锁定竞品与快照

每个快照确认站点、ASIN/变体、卖家/Offer、币种、采集时间、价格字段含义和材料位置。商品或卖家无法唯一对应时分列，不以标题相似合并。

只有一个快照时只做横截面和未来基线；至少两个范围与字段定义一致的快照，才能判断涨价、降价或促销变化。

## 2. 分开价格层次

分别记录页面价、划线价、Coupon/折扣后价、会员价或其他可见优惠。没有明确适用条件和计算顺序时，不自行推导“最终成交价”。

缺失、未返回或解析失败不是零。来源冲突时并列原值、时间和定义，不取平均。

## 3. 三 MCP 的合理分工

- SIF：ASIN 当前画像、销量或流量趋势等市场背景。
- SellerSprite：Coupon/价格历史；`keepa_info` 只是 SellerSprite 转述的 Keepa 画像，不是独立 Keepa 调用，也不是 Amazon 一方价格、销量或库存真相。
- Sorftime：商品、销量和流量趋势；不能证明正式活动资格或 Deal 状态。

记录供应商、实际工具、对象/站点/期间、原始值、可复查位置和限制。三方只有对象、时间、币种和定义一致时才比较，绝不平均。

## 4. 判断变化与影响

逐竞品说明：

- 哪个价格层或可见优惠发生变化；
- 直接快照依据；
- 变化幅度与适用窗口；
- 可能影响的用户决策；
- 其他解释，例如卖家切换、变体变化或页面展示差异。

## 5. 响应不是机械跟价

响应候选应同时考虑专家 14 的价格/贡献底线、当前活动目标、库存和品牌边界。可考虑保持、加强价值表达、调整计划群、缩短窗口、等待更多快照或停止响应。

每项写明直接依据、理由、风险、前置条件、观察窗口和人工批准人。不得承诺转化提升或自动改价。

## 6. 降级

快照不可比、覆盖不完整或工具失败时，交付已确认事实、差异、不能下的结论、最小补充材料和下一责任人。
