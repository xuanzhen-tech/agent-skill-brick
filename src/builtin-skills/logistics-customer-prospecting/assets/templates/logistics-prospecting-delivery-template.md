- [ ] 每个销售线索可回溯到平台记录、主体和联系方式 Evidence。

- [ ] 目的性样本没有被外推成总体成功率。
- [ ] 没有保存 API Key、Cookie、密码或其它运行时凭据。
- [ ] 没有自动发送消息、外呼或创建营销任务。
