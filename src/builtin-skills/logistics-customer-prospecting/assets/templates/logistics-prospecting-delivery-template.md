# 物流客户拓客 Excel 交付模板

> 由 `../../SKILL.md` 在正式交付时物化；字段和状态遵循 `../../references/prospecting-evidence-contract.md`。本文件定义工作簿结构，不要求把这些说明复制到交付文件中。

## 工作簿合同

- 默认文件：`outputs/sales-prospecting/<run-id>/logistics-prospecting-<run-id>.xlsx`
- 默认严格 4 个 Sheet：`线索与首联`、`联系方式证据`、`主体与复核`、`批次摘要`。
- 仅当用户明确要求独立管理话术时，增加第 5 个 `首联话术` Sheet。
- 不按平台、国家、渠道、企业或状态拆 Sheet；使用列和筛选器表达这些维度。
- 不把完整工作簿重复输出为 Markdown；聊天只返回摘要和正式文件路径。

## Sheet 1：线索与首联

一行一个企业，按 `优先级`、`线索状态`、`公司名称` 排序。关键字段必须位于前 12 列，便于首屏扫描：

| lead_id | 优先级 | 公司名称 | 地区 | 产品/行业 | 画像适配依据 | 首选渠道 | 首选联系方式 | 联系可信度 | 首联话术 | 线索状态 | 下一步 | 法定主体 | 主体状态 | 数据新鲜度 | 负责人 | 下次行动时间 | 证据引用 | 限制/未知信息 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | A/B/C | | | | | 邮箱/电话/官网/WhatsApp | | | | | | | | | | | | |

首联话术要求：

- 默认每条 80 至 160 个中文字符或语义等量英文，适合人工审核后发送；
- 先说明联系原因和可验证的匹配点，再提出一个低压力的下一步；
- 不声称知道对方货量、物流商、价格痛点、采购计划或决策权；
- 不自动发送；`线索状态` 最高只能是 `ready_for_human_outreach`；
- 若证据不足以个性化，填写“需补证后生成”，不得使用虚构事实填满单元格。

## Sheet 3：主体与复核

使用 `记录类型` 区分 `entity_evidence`、`manual_review` 和 `suppression`，统一通过对象 ID 回溯，不再拆成三个 Sheet。

## Sheet 4：批次摘要

本 Sheet 按从上到下三个区块排列，不额外拆 Sheet：

1. `批次概览`：`run_id`、画像版本、平台/数据源、查询词、站点、语言、范围/费用上限、开始与完成时间、样本类型和本批限制；
2. `采集任务`：`provider`、工具/模板、`task_name`、任务 ID、`lot_no`、状态、返回行数、分页覆盖、成本、错误和恢复动作；
3. `质量指标`：发现相关率、唯一主体率、商务联系方式覆盖率、人工复核率、异常联系方式排除率、可人工首联线索率和每个唯一可联系企业成本，均保留分子、分母、结果和限制。

## 可选 Sheet 5：首联话术

只有用户明确要求独立话术表时使用：

| 话术 ID | lead_id | 公司名称 | 渠道 | 主题/开场 | 正文 | 个性化证据 | 禁止声称的信息 | 人工审核状态 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | 待审核 |

此模式下 `线索与首联` 的“首联话术”列改为“话术摘要”，并增加“话术 ID”；不得在两个 Sheet 重复完整正文。

## 可读性和验证

- 每个 Sheet 冻结首行并启用筛选；数据区域采用一致表格样式，不使用合并单元格。
- 表头加粗；文本自动换行；公司、适配依据、首联话术和限制列设置合理宽度，其余列避免过宽。
- 日期写为日期值，数量和成本写为数值，百分比写为百分比，不把数值伪装成带单位文本。
- 用克制的条件格式突出 A 级线索、待复核、证据冲突和抑制记录；不得用大量颜色替代状态字段。
- 空值保持为空或使用合同中的明确状态，不写“0”冒充未知。
- 交付前确认工作簿可打开、Sheet 数量和顺序正确、主外键完整、无公式错误，并抽查首表记录能回溯到证据表。
