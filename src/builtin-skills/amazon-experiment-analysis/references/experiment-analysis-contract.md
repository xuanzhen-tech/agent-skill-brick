# 实验分析方法

## 1. 三个不同对象

- **Assignment**：被分到哪个组；
- **Exposure**：实际看到了哪个版本；
- **Outcome**：之后发生了什么。

三者不能互相替代。只按曝光比较可能失去随机化优势，需保留 ITT 作为主要或关键敏感性分析。

## 2. SRM

样本比例失配检验分配数量是否符合预期。显著 SRM 可能来自：

- 分流实现错误；
- 日志丢失；
- 资格规则不对称；
- 版本发布失败；
- 机器人或重复对象处理；
- 分析过滤破坏随机化。

SRM 是警报，不直接说明哪项原因。

## 3. 样本量

样本量应由基线、方差、最小有意义效应、显著性、检验力和设计效应决定。只写“跑两周”不等于样本量设计。

## 4. 不显著的正确解释

### 正例

“点估计为 +1.2%，95% 区间为 -0.8% 到 +3.2%；当前数据不能排除小幅损失，也不能确认达到 +2% 的业务目标。”

### 反例

“p>0.05，所以两个版本完全一样。”

## 5. 多重比较

若同时查看多个指标、分群或时间点，应预先指定主要指标，并对其他分析做校正或标记探索性。只报告显著结果会放大假阳性。

## 6. 护栏

主指标改善时仍检查：

- 退款、退货和客服问题；
- 广告或促销成本；
- 库存和履约；
- 页面质量、合规和品牌风险；
- 长期留存或复购。

不应为短期转化牺牲关键护栏。

## 7. 外部背景

市场、竞品、排名和季节趋势可以解释实验期间环境是否异常，但不能替代实验分配与结果。它们也不能让一个失败的随机化设计重新获得因果解释。
