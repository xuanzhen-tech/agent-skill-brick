# Price Optimization Tool

## 适用场景与边界
用于 SKU 定价、促销定价、跨市场价格同步、利润下滑诊断和价格战应对。目标是在销量、转化、Buy Box/搜索竞争力和贡献毛利之间做可解释取舍。

不适用于操纵价格、虚假原价、误导折扣或违反平台价格政策。不同国家税费、币种和配送成本必须分开计算。

## 输入信息清单
- 成本：采购、包装、头程、关税、仓储、尾程、平台佣金、支付费、退货、客服、广告和促销。
- 市场：竞品价格、评价数、配送时效、优惠、套装、品牌力和库存状态。
- 业务目标：利润最大化、清库存、冲排名、获取 review、进入新品期或防守 Buy Box。
- 历史数据：价格变化、曝光、CTR、CVR、订单、毛利、退款和广告成本。

## 优化流程
1. 建立 SKU 贡献毛利底线，先算“最低可接受价格”和“目标利润价格”。
2. 画竞品价格带，区分同质竞品、品牌竞品、低质低价和高端替代品。
3. 判断价格敏感性：观察历史调价后的流量、转化、订单和利润变化。
4. 设计价格动作：常规价、优惠券、捆绑、阶梯折扣、会员价或清仓价分别测试。
5. 设停止条件：低于毛利底线、库存风险、退货恶化或平台价格合规风险时停止。

## 关键指标与判断标准
看售价、毛利率、贡献毛利、CVR、AOV、ROAS、TACOS、库存周转和退货率。订单增加但贡献毛利下降，不应算成功；降价带来转化提升但广告效率不变，可能只是利润让渡。

价格优化必须按 SKU 和市场单独判断。高运费、大件、易退货或认证成本高的商品，不应照搬轻小件价格策略。

## 可执行输出
输出成本模型、竞品价格矩阵、价格测试方案、促销日历、毛利底线、调价规则、异常告警和复盘表。

## 风险与合规
注意平台价格欺骗、虚假折扣、MAP、税费显示、货币换算和跨渠道价格冲突。不得建议先涨价再打折制造虚假优惠。

## 示例
一个 SKU 售价 29.99 美元，竞品集中在 24.99-27.99。若该 SKU 有更好评分和 WFS/快速配送，可测试 27.99 加优惠券；若评分低且配送慢，应先修页面和履约，而不是单纯压价。

## 验证方式
至少观察一个完整购买周期，比较转化、订单、广告效率、贡献毛利和库存周转。促销结束后要看价格恢复能力，避免形成永久折扣依赖。
