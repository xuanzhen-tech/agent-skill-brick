# Walmart Seller Guide

## 适用场景与边界
用于新卖家入驻、已有店铺诊断、类目扩张、账号绩效修复和 Walmart Marketplace 年度运营规划。重点不是泛泛介绍平台，而是把“能不能卖、卖什么、怎样刊登、怎样履约、怎样拿到 Buy Box、怎样复盘利润”落到具体表格和动作。

不适合作为法律、税务或产品安全认证的最终意见；涉及 FDA、CPSIA、EPA、FCC、UL、Prop 65、进口税则和商标授权时，应列出需要人工确认的材料和责任人。

## 输入信息清单
- 入驻与账号：公司主体、美国税务资料、银行信息、仓库/3PL、历史平台经营记录、目标类目和品牌授权。
- SKU 与经济模型：UPC/GTIN、类目、成本、售价、竞品价、毛利、库存、尺寸重量、退货率、保修承诺。
- 刊登资料：标题、key features、description、attributes、图片、变体关系、compliance docs、item setup 错误。
- 履约与服务：WFS 或自发货、配送时效、取消率、迟发率、valid tracking、退货政策、客服 SLA。
- 增长数据：Content Quality、Buy Box、曝光、点击、转化、Walmart Connect、促销、review 和 seller scorecard。

## 操作流程
1. 先确认账号与类目准入，分清“可以直接上架”“需要合规资料”“不建议进入”的 SKU。
2. 建立 SKU 经济模型，把平台佣金、WFS 费用、尾程、退货、广告和促销全部纳入贡献毛利。
3. 处理 Item Setup：优先修复 GTIN、类目、属性、变体、图片和合规字段，避免商品虽然在线但不可发现或不可购买。
4. 提升内容质量：标题覆盖核心词，key features 解释购买理由，attributes 补齐筛选项，图片展示尺寸、场景、包装和差异点。
5. 争取 Buy Box：比较价格、库存、配送承诺、卖家绩效和竞品 offer，明确哪些 SKU 靠降价无意义，哪些 SKU 可以通过 WFS 或时效改善提升胜率。
6. 建立周复盘：每周按 SKU 输出流量、转化、Buy Box、广告、退货和利润，不用 GMV 单独评价经营质量。

## 关键指标与判断标准
Content Quality 低于同类目基线时，先修刊登再加广告；Buy Box 低且价格不具竞争力时，广告放量通常只会放大亏损。取消率、迟发率、valid tracking 和退货率会影响账号健康，必须与销售增长一起看。

判断一个 SKU 是否值得继续投入，应同时满足：有稳定库存、贡献毛利为正、页面质量可修复、价格带有竞争空间、退货原因可控。只靠短期促销冲销量但退货和广告成本失控的 SKU，应降级或停止。

## 可执行输出
输出应包括：入驻/合规缺口清单、SKU 上架优先级、Item Setup 修复表、内容优化 brief、Buy Box 诊断、WFS/自发货选择建议、广告启动条件、周度 scorecard 和 30/60/90 天路线图。

## 风险与合规
不得误填属性、滥用品牌名、使用未经授权图片、虚假配送承诺或规避 Walmart 规则。敏感类目需要先确认认证和标签要求；价格、促销和库存承诺必须与实际履约能力一致。

## 示例
一个家居收纳卖家准备进入 Walmart。应先筛掉没有 UPC 或认证不完整的 SKU，再选择 20 个毛利和库存稳定的 SKU 上架；首周修复 item setup 和图片，第二周观察 Buy Box 与 Content Quality，第三周只对内容质量合格且库存覆盖 30 天以上的 SKU 启动 Walmart Connect。

## 验证方式
用 14 天检查 item setup 错误、Content Quality 和可售状态；用 30 天检查 Buy Box、CVR、广告花费和贡献毛利；用 60 天复盘退货、取消、迟发和 seller scorecard。若页面质量改善但 Buy Box 和利润仍无改善，应回到价格、履约或 SKU 选择层面重判。
