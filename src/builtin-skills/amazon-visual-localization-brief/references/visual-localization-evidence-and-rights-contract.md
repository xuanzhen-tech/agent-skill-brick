# 视觉本地化证据与权利方法

## 一、三个业务门

1. **产品事实门**：产品形态、颜色、材质、部件、比例、包装、Logo、适用变体和禁止改变项均有可信来源。
2. **权利门**：源图片、品牌资产、字体、图标、人物、场景和参考素材的权利及可用范围明确。
3. **批准门**：市场方向、资产处理和高风险表达由正确责任方批准；候选方向不写成已批准结果。

任一门不满足时，明确受影响资产、允许继续的工作、被阻塞的生产动作和下一责任方。

## 二、本地化依据

可以使用：

- 用户提供并确认的产品、品牌和目标市场材料；
- 可信上游交付的关键词、VOC、Listing 或 A+ 需求；
- 本 Skill 实际调用 SIF、SellerSprite、Sorftime 获得的市场与关键词数据。

不能自动推断：

- 产品不存在的功能、配件、认证或使用结果；
- 某视觉风格必然提升转化；
- 未确认素材可商用；
- 历史平台规则仍然有效；
- 单一供应商估算代表完整市场。

实际调用 MCP 时，记录供应商和精确工具、站点与查询对象、范围、时间、筛选和分页、原始值及结果位置。关键参数要能追溯到用户输入或上游材料。多个来源只在口径可比时对照；冲突按来源拆开，不平均。

## 三、每项资产处理决定

记录：

- 资产名称、路径、版本、用途和适用站点/变体；
- 产品身份锚点和必须保持内容；
- 目标市场要解决的理解问题；
- 保留、替换、裁切、重构、重新制作或暂缓的具体动作；
- 直接市场/用户依据和 Agent 的判断；
- 源资产权利、允许使用范围和批准责任方；
- 禁止新增、文字叠加和语言要求；
- 跨资产一致性约束；
- 生产方式、验收、缺口和责任方。

## 四、跨资产一致性

全套资产共同核对产品形态、颜色、材质、部件、比例、包装、Logo、色彩系统、字体、光照和背景语言。单一资产返工时冻结已通过资产，完成后重新检查整体一致性。

## 五、生产交接

交给内置图像能力时，只传递已批准的产品身份、源资产、构图、场景、必须/禁止元素和验收条件；文字密集或需要精确排版的内容交给确定性工具或人工。未经权利确认或批准的资产不得进入生产。
