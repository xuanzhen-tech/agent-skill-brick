# HTML 样式规范

使用自包含 HTML 和内联 CSS。推荐变量：背景 #F8FAFC，卡片 #FFFFFF，主色 #7C3AED（我方），辅色 #06B6D4（竞品），正向 #059669，风险 #DC2626，正文 #1E293B，次要文字 #64748B，边框 #E2E8F0。

页面容器最大宽度 1100px，使用微软雅黑等中文字体。头部为圆角白色卡片、紫色底边；结论/警示/复刻使用带左色边的卡片；指标使用响应式卡片；表格必须可横向滚动。趋势图优先使用内联 SVG，不引用 CDN。用紫色表示我方、青色表示竞品、绿色表示正向、红色表示负向。时间线可用 CSS 相对定位和条形/圆点表示事件及拐点。

每张图表或数据表须在图后紧邻“图表解析”卡片，使用正文大小且不少于两条完整句。解析卡应包含观察、比较、经营含义和限制/验证；以文字标签区分“供应商估算/观察”“第一方数据”“待验证假设”，避免仅用颜色传达含义。

报表需适配窄屏、提供足够对比度，避免仅用颜色传达语义。
