# 买家索赔单案方法

## 1. 类型决定责任边界

A-to-z 与 payment chargeback 的通知主体、程序和可用材料可能不同。必须以原始通知为准，不把普通退款、A-to-z 和拒付混成同一流程。

类型不清时先索取完整通知，不根据标题、文件名或用户简称推断。

## 2. 期限验证

可验证期限需要：

- 原始通知或案件页显示的截止时间；
- 对应 marketplace；
- 明确时区或可定位的时区解释；
- 本次观察时间。

### 正例

案件页面明确显示某日期、时间和时区，截图完整，当前观察时点已记录；可以透明换算并计算剩余时间。

### 反例

邮件文件创建于周一，于是按记忆中的“72小时”推算周四截止。

## 3. 指控—证据分析

每项指控都应单独回答：

1. 买家或平台具体主张什么；
2. 哪些材料支持；
3. 哪些材料反驳；
4. 仍缺什么；
5. 材料覆盖哪个对象和时间；
6. 回应最多能表达到什么程度。

不要只收集有利材料。忽略相关反证会让草案失真，也会阻碍人工判断。

## 4. 时间线的证据强度

平台订单记录、承运商扫描、签收记录、消息原文、退款记录各自证明不同环节。时间线应保留来源原状态，不把“已发货”“已投递”“买家收到”视为同义。

未知事件不按常见流程补齐，观察截止后的记录也不能当作当时已知。

## 5. 附件选择

优先选择：

- 与某项指控直接相关；
- 来源、日期、订单和对象匹配；
- 内容完整、可读；
- 未经改变语义的剪裁；
- PII 已按最少必要遮蔽；
- 人工确认允许纳入。

重复、无关、无法读取、跨订单或暴露过多敏感信息的附件不应纳入。

## 6. 回应写作

每段回应应做到：

- 直接对应一项指控；
- 使用材料支持的事实；
- 引用相应附件；
- 坦诚说明缺口或冲突；
- 不给法律结论或结果保证。

如果材料只能证明“卖家于某日发起退款”，就不要写“买家已收到退款”。

## 7. 三 MCP 边界

三个市场研究 MCP 不能提供买家线程、订单、退款、索赔、期限或责任事实。公开 VOC 不进入单案证据。

时间线、证据分析和草案只基于合法单案材料，并在相应结论附近说明直接依据和限制。
