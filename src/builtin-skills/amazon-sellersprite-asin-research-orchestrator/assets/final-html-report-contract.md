# 最终 HTML 模板使用合同

## 唯一工作方式

1. 将 `assets/report-template.html` 原样复制到 `outputs/amazon-asin-research/<case_id>/report.html`。
2. 只编辑复制出的 `report.html`，不修改 Skill asset 源模板，不从空白 HTML 重写。
3. 完整阅读模板顶部注释和 `REPORT_DATA` 注释。业务事实默认只写入 `REPORT_DATA`；只有模板明确标注的扩展点允许扩展同类数据或必要渲染。
4. 用本次 MCP 返回、用户输入或可复算分析替换全部预览内容，将 `templateMode` 改为 `false`。
5. 正式交付仅呈递 `report.html`，不要求用户读取内部证据文件。

这是文本使用合同，不要求生成或运行额外校验脚本、Schema、SQL 或硬文件。Agent 应依据模板注释、证据和最终页面自行检查。

## 固定、替换、扩展和条件展示

- **固定结构**：保留报告概览、价格趋势图、订单趋势图、BSR 排名趋势图、评分趋势图、评论分析、变动监控七个一级部分，以及其顺序、导航锚点、DOM id、CSS 设计系统和主要交互。不得新增平级章节。
- **必须替换**：模板中的 ASIN、商品信息、日期、价格、订单估算、BSR、评分、评论主题、摘要、结论、媒体和变动记录全部是预览内容，正式报告不能保留。
- **分析派生**：核心结论、预警、各图表分析、主题与情感、提及率、评论摘要、评论趋势、日增评分数、异常筛查、归因与建议必须由本次证据重新分析或复算，并标明分母、公式、范围、证据或限制。
- **可扩展**：可在对应部分增加竞品、实际返回的 BSR 小类目、评论主题、预警、分析段、趋势事件和行动建议；对象与记录数量不得被模板示例限制。
- **条件展示**：未返回的可选价格线、主题曲线、竞品或变动记录可删除或显示真实状态；七个一级部分不得删除。缺失不补零，不保留演示值。

## 七部分数据要求

1. **报告概览**：对象头部、核心结论、目标 KPI、比较表和零到多条关键预警。字段只使用当前真实值；每条预警绑定证据和时间范围；数据状态区分就绪、部分缺失、未返回和不可比较。
2. **价格趋势图**：固定最近半年、日粒度。只绘制 MCP 实际支持且返回的商品售价、Buy Box、Listing Price、Deal Price、Coupon 最终价等系列；未支持的整条曲线不出现。
3. **订单趋势图**：固定最近半年、日粒度。所有值明确写作 SellerSprite/供应商估算，不表述为 Amazon 真实订单。
4. **BSR 排名趋势图**：固定最近半年、日粒度，说明越小越好。大类目和实际返回的小类目保持独立系列/轴；类目变化形成断点。
5. **评分趋势图**：固定最近半年、日粒度。星级与累计评分数来自来源；日新增评分数只由相邻日累计值差分派生，负值保留并说明修订可能。
6. **评论分析**：逐条评论是直接证据；主题、正负方向、提及数/率、摘要和趋势是分析派生。每个比例同时展示命中数与合格分母；ASIN、父体和类目样本分别说明覆盖；使用匿名 evidence ID、日期、星级和最小充分摘录进行溯源，不展示评论者身份画像。
7. **变动监控**：固定包含评论比例代理、评论异常筛查、交互事件时间线、L1/L2/L3 归因、数据溯源与可信度、行动建议。标题、Bullet、图片 URL、价格、订单估算、评论、评分和排名的变动前后值只进入图表事件 Tooltip，不再独立展示 diff 表；无历史时标明已建立基线。每个材料性拐点还必须展示直接因素、间接因素、好坏/混合/未知影响、目标与竞品同口径对比、可验证建议、替代解释、证据和置信度。预测必须与观察事实分层并说明概率/失效条件。

店铺新品和广告/流量结果不是独立章节。只有真实且材料性足够时，作为概览证据、既有图表事件标记或就近补充卡片使用。

## 图表与证据表达

- 图表是报告核心，保持模板规定的宽幅、Tooltip、图例、日期缩放和对象切换；文字负责读图、解释和限制。
- 价格、订单、BSR、评分和评论图之后必须出现本次证据驱动的分析块，包含读图结论、证据引用和限制；不能只有图，没有分析。
- 价格、订单、BSR 和评分保留完整半年日级数据，同时允许用户通过日期输入或底部缩放条框定子区间；选区比较按该范围内首尾真实有效值计算，不沿用全期结论，并在图内浮层实时展示，不在图后生成松散摘要卡。
- 普通日期悬停只展示该日原值；材料性拐点使用醒目标记和富 Tooltip。富 Tooltip 中的因素、影响、比较和建议必须由 Agent 基于跨模块证据写入 `REPORT_DATA.events`，渲染函数不得临时生成业务判断；缺证据时明确“尚未形成”。
- 概览预警、图表事件和分析段数量随证据灵活调整，不设置模板固定条数。
- 价格、订单估算、BSR 和评分默认使用截至采集日最近半年自然日，最小粒度 1 天。实际覆盖不足时保留真实日期和空缺，不复制、插值或补零。
- 每张图就近说明对象、期间、单位、数据性质和限制；估算、派生值、未结束期、范围断点和类目变化必须可见。
- MCP 未返回的数据保持 `null`、空集合或真实状态。Tooltip 不把缺失显示为 0，图线不跨不可比断点。
- 图片只使用真实 `embedded | remote_reference | metadata_only | unavailable` 状态。不要使用 `asset1`、`XXX` 等无业务语义占位名；未取得图片时显示准确状态。
- 证据ID必须来自本次 MCP 响应定位或工作区证据文件，不能照搬样例中的 `SS-`/`RV-` 后台快照号，也不能声称工具未提供的追溯能力。

## 正式交付前自查

- 七个一级部分、顺序、导航和核心交互仍在。
- `templateMode=false`，模板预览提示已隐藏。
- 没有模板 ASIN、数字、主题、摘要、结论、图片或变动记录。
- 没有 CDN 或其他外部脚本依赖；仅远程图片可作为明确标注的外部依赖。
- 图表与文字使用同一对象、日期、粒度、单位和 dataset version。
- 缺失、估算、派生、不可比、未结束期和证据限制没有被隐藏。
- 最终只向用户呈递 `report.html`。
