# 营运资金行动控制方法

## 1. 行动必须由领域 owner 拥有

现金分析可以说明约束，不能自行决定减少补货、停广告、取消促销或延迟税费。原行动、对象和业务后果由领域责任方确认。

## 2. 现金影响

现金影响至少需要金额、币种和时间。利润改善不一定立即释放现金，推迟支出也可能只改变时间而非总额。

### 正例

已批准 PO 的第二笔付款可在供应商书面同意后推迟 14 天，金额、日期和取消/延迟后果有合同与采购 owner 确认。

### 反例

库存过高，因此把未来采购成本全部写成“可释放现金”。

## 3. 可推迟性

检查最晚决策日、外部承诺、取消费、恢复时间、缺货/销售/合规后果和领域 owner。缺一关键点时只能写“待确认”。

## 4. 审批与承诺

内部批准不等于外部承诺，外部承诺也不证明内部批准。分别记录：

- 谁决定；
- 何时决定；
- 对什么范围；
- 有什么材料；
- 如何撤销或变更。

## 5. 行动比较

比较应同时看：

- 现金释放金额和时点；
- 对收入、利润、库存与合规的影响；
- 可逆性和恢复成本；
- 依赖与截止时间；
- 不确定性。

若币种、期间或情景不同，应先转换/对齐或分开展示。

## 6. 外部需求

供应商趋势只能为“需求高于/低于基准”的压力情景提供背景。它不能替代正式库存、销量、成本或现金流，也不能自动改变补货等动作。
