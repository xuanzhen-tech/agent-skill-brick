# FX 与回款分析方法

## 1. 同一交易链

先证明平台结算、渠道换汇和银行到账属于同一笔或可解释批次。金额相近和日期接近不足以自动联接。

### 正例

Payout ID、渠道批次和银行附言可联接；一笔 payout 分两次到账，分拆金额与费用可核对。

### 反例

把同一天所有银行入账合并后与某个 Amazon payout 比较。

## 2. 有效率

若源币金额为 `A_s`、目标币金额为 `A_t`：

`有效率 = A_t / A_s`

必须声明 `A_t` 是结算金额还是银行净到账，以及费用是否已扣。

## 3. 参考率与实际率

参考中间价用于衡量机会成本，不是可成交报价。实际率应基于同一交易的真实金额。比较时要考虑时间差和费用。

## 4. 差额分解

从用户选择的参考率计算理论目标币金额，再依次扣除汇差、显式费用和已知其他扣款。剩余项保留“未解释”，不要强行归类。

## 5. 情景

情景汇率应由用户批准，结果展示金额敏感性，不附发生概率。多个情景都使用相同暴露金额、费用和时间基准。
