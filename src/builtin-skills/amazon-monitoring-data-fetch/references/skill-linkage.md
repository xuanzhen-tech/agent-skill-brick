# 后续运营复盘联动

本 Skill 的 `price.csv`、`orders.csv`、`bsr.csv`、`rating.csv`、`listing_changes.csv` 可作为后续运营复盘与竞品动作还原流程的核心输入；评论和关键词是补充证据。

后续复盘前先确认每个序列的 `marketplace`、ASIN 身份和父子体层级一致。不同站点的数据不能直接合并或据此做单一趋势/归因判断；跨站比较必须保留站点、币种、类目和采样口径差异。

通常需要变更前至少 14 天基线和变更后至少 7 天观察期。时间范围不足或 Listing 变更缺失时，必须降低因果判断置信度或只提供趋势分析。当前环境未安装兼容的下游能力时，不得声称已自动执行复盘。
