# 统一证据与主张等级合同

## 合同目的

本文件是集群唯一 L0–L4 定义来源。六个 Skill 的 SKILL.md 正文开始前必须显式声明已读取本文件。禁止任何模块复制、改写或隐含使用另一套等级定义。

## L0 – 不可知

### 触发条件（满足任一即为 L0）
- 只有一个快照且无合格基线
- 站点、ASIN、父子体/变体身份不稳定或冲突
- 字段定义、单位、币种、时间粒度未知或混用
- 返回被截断且无法缩小范围补齐
- 关键字段未返回且无代理指标可替代
- 数据来源不可定位

### 允许措辞
"证据不足，无法判断"
"当前数据不能支持关于……的任何结论"
"需补充……后方可评估"

### 禁止
- 输出任何数值变化、方向判断或候选解释
- 把缺失写成零、不存在、未投放、未修改
- 用"可能""似乎"绕过 L0

---

## L1 – 观察事实

### 最低条件（必须全部满足）
1. 同一 marketplace、同一 ASIN/变体、同一字段语义
2. 数据来源、精确工具、查询参数、原始响应位置可追溯
3. 字段含义、单位/币种、时间戳明确
4. 对趋势/序列：至少两个通过可比性门的同口径快照
5. 原始值未被加工为第一方事实（销量是估算、广告是供应商观察）

### 允许措辞
"SellerSprite 在[查询时间]对[站点][ASIN]返回……"
"在[窗口]内，SellerSprite 观察到[字段]从[前值]变化至[后值]"
"该变化幅度为[绝对变化/相对变化]，方向为[上升/下降/持平]"

### 禁止
- 把 SellerSprite 估算/预测写成 Amazon 真实订单、会话、广告指标
- 声称变化由某个原因导致
- 单快照使用"变化/趋势/拐点/改善/恶化"
- 未返回字段写成"无""不存在""未使用"

---

## L2 – 多信号异常模式

### 最低条件（必须全部满足）
1. L1 全部条件
2. 至少两类不同字段通道的信号（如价格+销量、BSR+评论、流量词+广告排名，必须是 SellerSprite 不同 endpoint 或不同语义族的返回）
3. 信号在时间窗口、ASIN 范围和影响方向上一致，且时间先后合理
4. 已列出至少两个替代解释
5. 覆盖/截断/缺失状态已记录

### 重要约束：同源多维 ≠ 多源独立
SellerSprite 不同 endpoint 属于同一供应商，不能因调用了三个不同工具就声称"三源验证"。L2 不要求独立来源，但必须在报告中标注"同源多维观察，非独立多源交叉验证"。

### 允许措辞
"多个 SellerSprite 可见信号在[窗口]内同向变化，形成异常模式候选"
"评论增长节奏、评分集中度与销量估算的变化存在需复核的不协调"
"该组合与[候选机制]的外部表现一致，但无法确认内部原因"

### 禁止
- 声称"刷评""操纵""虚假评论""人为干预"等事实认定
- 把同源多端点写成"多方印证"
- 仅凭单一字段异常升至 L2
- 省略替代解释

### 对评论异常的封顶规则
即使满足 L2 全部条件，SellerSprite-only 的评论异常结论**不得**超越 L2。可达措辞上限为"存在需人工复核的评论异常模式"。

---

## L3 – 较强候选机制

### 最低条件（必须全部满足）
1. L2 全部条件
2. 候选事件的发生时间先于结果变化（时序证据充分）
3. 至少三个不同信号族同向，且影响范围与候选机制的逻辑范围一致
4. 已系统检查并记录至少三类混杂因素：季节性/大促/节假日、变体/父子体/类目变化、数据管道/供应商变更
5. 已给出可证伪条件（"若观察到 X，则当前假设可能被推翻"）
6. 事件预注册：窗口和候选机制必须在分析前冻结，不可事后挑选有利窗口

### SellerSprite-only 能否达到 L3？
**允许，但需要额外强制条件：**
- 必须包含来自不同 SellerSprite 工具族的信号（如 keepa 历史序列 + 流量关键词 + 评论时间分布，而非同一工具的不同字段）
- 必须在报告中用独立一节说明"本结论基于单一供应商的多端点观察，未经独立外部来源核验"
- 总控有权将模块自评 L3 降级为 L2，如果发现时序证据不充分或混杂检查不完整

### 允许措辞
"[候选机制]是现有 SellerSprite 可见证据下的较强候选解释"
"该机制与价格、BSR、流量词和评论的四组信号在时间、方向和范围上一致"
"仍缺少[具体一方数据/实验]方可确认因果"

### 禁止
- 声称"根因""已证""归因确认"
- 把同源多端点包装为独立证据后升级
- 隐去"候选"限定词
- 事后挑选窗口

---

## L4 – 已确认

### 最低条件（必须全部满足）
1. L3 全部条件
2. 具有可核验的一方数据 或 独立外部来源 或 有效实验/准实验设计
3. 一方数据来源、字段、期间、口径和限制已记录
4. 对照/实验设计、分组、指标和潜在混杂已记录

### SellerSprite-only 能否达到 L4？
**不能。** SellerSprite 是单一外部供应商，缺少第一方订单/广告/库存/操作日志或独立实验设计。L4 需要至少一项 SellerSprite 之外的有效证据。

### 允许措辞
"基于[一方数据/实验/独立来源]与 SellerSprite 观察的交叉核验，确认……"
"在[具体材料]范围内，已确认……仍限定于该范围"

## 模块最大等级速查

| 模块 | SellerSprite-only 最大等级 | 附条件 |
|---|---|---|
| 市场竞争格局 | L3（市场结构/定位推断） | 需要至少三个独立工具族信号 |
| 事件与异常分析 | L3（候选机制） | 需要事件预注册+三族信号+混杂检查 |
| Listing 竞品审计 | L2（字段差异） | 历史差异需要两个可比快照，当前快照仅 L1 |
| 广告可见性与关键词缺口 | L2（可见性信号） | L3 升级需一方广告报表或独立广告可见性来源 |
| 评论 VOC 与异常筛查 | L2（异常模式） | 评论人为干预认定不可超越 L2；VOC 主题 L1 |

## 升级与降级规则

- **升级**：满足高级全部条件且低级条件未退化，逐级升级，不可跳级
- **降级**：任一下级条件出现新缺口（如数据被截断、口径变化、发现未检查的混杂），立即降回对应等级
- **总控裁决**：总控对冲突或夸大的自评等级有最终裁决权，裁决需记录原因r
