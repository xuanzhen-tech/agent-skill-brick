# 异常矩阵决策辅助

## 适用目的

这是多信号筛查的可复现性辅助工具，不是欺诈检测模型，也不包含合规或行业阈值。

## 候选构建

将一个候选定义为一个 ASIN 范围和一个已完成的日历分桶。基线和候选使用相同分桶单位。保留预先声明的滞后集合，以及每个已评估滞后的全部结果，包括无结果或冲突结果。

## 信号分类

当信号计算有效时，标记为 `observed`。候选只有在以下条件全部满足时才可成为 `screen_positive`：

1. 至少两个不同的描述性信号族在同一分桶或合理的滞后对齐分桶中一致。
2. 基线完全可比，或唯一限制已明确界定且不可能合理地产生该模式。
3. 分页覆盖、父子映射与字段定义已通过检查。
4. 至少记录一个实质性替代解释和一个反向检查。
5. 未作出任何禁止推断。

任一结构性范围或覆盖检查失败时，使用 `explained_by_scope_change`、`insufficient_coverage` 或 `not_calculable`，而不是 `screen_positive`。

## 建议的反向检查

| 候选信号 | 最低反向检查 |
| --- | --- |
| 评论/销量估算比例变化 | 所有预先声明滞后；销量范围及估算定义；评论发布延迟解释 |
| 日期集中 | 完整分页覆盖；分桶边界/时区一致性；小样本量背景 |
| 星级或情感构成变化 | 筛选、codebook 与编码总体未变；星级字段可用性 |
| VP/Vine/媒体/语言构成变化 | 返回值与缺失字段比率；供应商字段/schema 变化；样本/筛选迁移 |
| 近重复集中 | 原语言比较；确定性方法；常见短语或转载内容替代解释 |
| 父子体不连续 | 前后身份登记；子体纳入规则与评论池范围 |
| Coupon/价格/BSR 等上下文信号 | 同日或同分桶来源链；促销、库存、排名/模型变化替代解释 |

## 交接标准

仅在完成矩阵后交接。接收负责人需要可追溯数据和明确的验证请求，而不是指控、举报或联系任何人的建议。
