# 语料验收与分页覆盖协议

## 目标

在进行文本编码、比率计算或时间序列筛查前，明确 SellerSprite 返回评论语料所代表的范围。返回数量不会自动等于总体数量。

## 分页台账流程

1. 冻结市场、ASIN 变体范围、筛选条件、排序、页大小和目标期。
2. 将 `review` 工具 schema 及每个请求/响应对记录到查询日志。
3. 对每个分页请求记录：请求 token 或页码、请求大小、返回大小、下一页或终止标记、响应定位符、压缩/截断状态、评论日期范围和字段可用性。
4. 按 Skill 中的计划继续执行。没有终止标记的满页不能证明没有下一页。
5. 区分来源报告的零值、空结果、失败请求、不可用字段、压缩响应和未查询页。

## 验收判定

- `complete_for_plan`：每个计划页均完成且观察到终止条件，或计划定义了有界样本且每个计划页都已获得且未截断。
- `partial_pages`：部分计划页未返回，或存在请求失败。
- `unknown_page_ceiling`：不存在可信终止条件，且计划无法确定上限。
- `provider_coverage_insufficient`：供应商响应被压缩、截断，或因其他原因无法在记录层面审计。
- `failed`：在合同允许的重试行为后，仍无法完成必需查询。

有界计划样本可支撑对该样本的描述性结论，但不得称为 ASIN 的完整评论总体。

## 验收台账计算

以下值必须分开使用：

- `raw_returned_n`：已记录页面中返回的全部原始记录对象。
- `eligible_pre_dedup_n`：冻结范围内、文本可定位且可安全脱敏的记录。
- `exact_duplicate_n`：按稳定 ID 或完整确定性指纹规则移除的记录。
- `possible_duplicate_n`：保留在分母中、仅标记人工检查的记录。
- `eligible_dedup_n`：用于分母的 canonical 合格记录。
- `not_codable_n`：符合资格但无法编码的记录，单独报告。

除非已返回并审计与所显示总数相对应的完整项级文本语料，否则不得将显示的汇总评论总数用作文本提及率分母。

## 跨期验收

比较要求市场、冻结 ASIN 范围、分页计划、筛选、排序、资格规则、去重规则版本、codebook 版本和关键字段覆盖稳定。任一条件变化时，标记为 `partially_comparable` 或 `not_comparable`，并保留独立快照。
