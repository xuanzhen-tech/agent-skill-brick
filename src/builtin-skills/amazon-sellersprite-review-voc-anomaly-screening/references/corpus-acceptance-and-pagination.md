# 评论语料验收与分页

## 分页和范围

1. 冻结 marketplace、ASIN/变体、目标期、语言、筛选、排序、页大小和有界采集计划。
2. 记录实际工具 schema 及每个请求/响应。
3. 每页记录请求页/token、请求/返回大小、下一页或终止标记、响应定位、压缩/截断、评论日期范围和关键字段。
4. 没有终止标记的满页不能证明没有下一页。
5. 区分来源真实零值、空结果、失败、字段不可用、压缩和未查询页。


## 时间语义、参数行为与本地窗口

1. 先以小样本确认实际返回的评论日期字段、时间单位、站点/时区语义，以及默认排序和分页行为；记录证据。
2. 对 `startTimestamp`、`endTimestamp` 或其他服务端时间筛选，使用至少两个明显不同且不重叠的短窗口验证返回记录的日期范围是否改变。Schema 接受参数不构成参数已生效的证据。
3. 若服务端过滤未按已验证的评论日期生效，改用“全分页或有界分页原料 + 本地按 `review.date` 包含式筛选”；本地筛选规则必须保存起止站点日、边界、转换方法与每条记录的来源页。
4. 逐条评论是最细优先原料；日、周、月或其他时间桶仅在原始日期覆盖、对象与样本量允许时派生。采用实际可审计的最细合格时间桶，不因日级稀疏而伪造连续日趋势。
5. 本地允许清洗 HTML、规范化文本、确定性去重、对象/语言/日期过滤、主题编码、聚合和差分；不得补造评论、猜测缺页、把当前累计数补成逐条记录，或将不同对象范围混合。

## 验收状态

- `complete_for_plan`：计划页全部完成且有可信终止，或有界样本全部获得且未截断；
- `complete_with_scope_limit`：分页与记录覆盖可验收，但对象为明确的父体/变体池或其他受限范围；
- `partial_pages`：计划页缺失或请求失败；
- `unknown_page_ceiling`：无可信终止且无法确认上限；
- `provider_coverage_insufficient`：响应压缩、截断或无法记录级审计；
- `failed`：允许的有界重试后仍无法取得必需语料。

结果使用规则：`complete_for_plan` 可报告该明确对象范围内的主题率和时间趋势；`complete_with_scope_limit` 可报告受限范围结果且必须在标题与分母中披露范围；`partial_pages` 可报告“已返回样本”的主题、摘录及样本内构成，不得称 ASIN 全量、总体率或跨对象优劣；`unknown_page_ceiling` 仅报告可定位摘录、已返回样本观察和质量风险。不得将缺失、未知页或样本外部分画为零。

## 分母

分别记录：`raw_returned_n, eligible_pre_dedup_n, exact_duplicate_n, possible_duplicate_n, eligible_dedup_n, not_codable_n`。

主题提及率使用 `eligible_dedup_n` 或已声明分层后的合格评论数。正式结果同时返回 `mention_review_n` 和 `eligible_review_n`，不能只给百分比。除非逐条语料完整覆盖并审计，不得使用商品页显示的总评论数作为文本主题分母。

## 时间桶和跨期

每个时间桶单独记录返回数、合格数、缺失字段、分页状态、对象范围和 `bucket_unit`。缺失时间桶不是零。时间桶应采用实际可审计的最细粒度；若日级样本过稀或窗口覆盖不稳定，可聚合为周级或其他明确粒度，不能插值补点。

跨期趋势要求 marketplace、ASIN/变体、分页计划、筛选、排序、资格、去重、codebook 和关键字段稳定；变化时分段或标记 `not_comparable`。ASIN、父体和类目样本分别建立覆盖与分母，不能借一个层级的总数替代另一个层级。父体或类目样本没有合格覆盖时不返回对应趋势线，不把缺失画成零。
