# 透明评分模型

## 评分的角色

评分用于回答“先验证谁”，不是自动回答“做哪个”。先做硬闸门，再评分；评分之后仍需检查单位经济、数据覆盖和关键风险。

## 维度设计

默认五维只是起点：

| 维度 | 建议证据 | 分数方向 |
|---|---|---|
| `demand` | 销量销额、需求趋势、关键词搜索与购买趋势 | 稳定或增长且多证据一致更高 |
| `competition` | 商品/品牌集中、竞品数量、评分评论门槛、点击集中 | 集中度低、进入壁垒可解释更高 |
| `new_product_acceptance` | 新品数量、近 1/3/6/12 月新品销量销额占比 | 新品可获得真实份额更高 |
| `differentiation` | 价格带空档、关键词供需缺口、可验证痛点、用户产品能力 | 证据明确且可实现更高 |
| `unit_economics` | 用户成本模型的 CM3、保本价与敏感性 | 压力情景仍成立更高 |

若任务需要改维度，保持机器名稳定、含义单一，并在配置中声明。

## 从原始指标到维度分

每个指标必须声明：

1. 原始字段、工具、期间和数据类型；
2. 越大越好、越小越好或区间最佳；
3. 变换方式：线性、对数、枚举或分位数；
4. 低分锚与高分锚；
5. 锚点依据：用户约束、同类目分布或明确业务闸门；
6. 截断规则。

优先使用同站点、同类目、同期间的 P10/P50/P90 等分位数校准。样本过小或不完整时，不得伪装成稳定分位数。

线性示例：

```text
正向分 = clamp((x - low) / (high - low), 0, 1) * 100
反向分 = clamp((low - x) / (low - high), 0, 1) * 100
```

对 BSR、销量和搜索量等偏态指标，可在声明后使用对数变换。区间最佳指标应明确上下界和区间外衰减方式。

同一维度含多个指标时，先打印子指标权重，再求维度分。冲突证据不应被无声平均；在维度备注中解释。

## 硬闸门

硬闸门与评分分开：

- 用户明确禁售、超预算或不满足物流边界；
- 关键合规状态未知且用户不接受继续验证；
- 完整成本模型在基准情景已明显为负；
- 关键数据被证实错误或口径不可比。

`fail` 直接导致 `kill`；`watch` 将最终决策上限限制为 `watch`。

## 缺失值与覆盖

- 缺失维度不填 0、不填均值。
- 用剩余维度按原权重比例重归一化：

```text
总分 = sum(可用维度分 * 原权重) / sum(可用原权重)
```

- 报告必须打印可用权重、缺失权重和缺失维度。
- 本次配置必须声明 `missing_weight_stop`。缺失权重严格大于该值时不给总分。
- 即使总分存在，`demand` 或 `unit_economics` 未达到 `ready` 时也不得给 `go`。
- 评分工作表必须显式声明 `required_for_go`，且至少包含 `demand`、`unit_economics`；不得依赖空列表或隐含默认值。
- `partial` 维度可以参与计算，但必须在报告标出，并由人工判断是否下调决策。

## 证据记录合同

有分数的维度必须携带结构化 `evidence`，而不是只有不可解释的字符串 ID。每条至少声明来源、数据类型、时间角色、工具和日期/期间。

- 需求维度要判为可评分，至少需要明确数据期间且当前或历史覆盖足够；只有单点或时间未返回时必须降为部分证据。
- `unit_economics=ready` 必须来自内置利润包的正式输出或等价且已复核的用户成本对象；任一供应商利润率、潜力指数或 SIF 探索性利润门槛都不能满足该条件。
- MCP 原始证据必须记录供应商、精确工具、站点、对象、期间、覆盖、原值和原始结果位置；请求 ID 只在真实返回且排错确实需要时保留。
- Agent 评分必须在对应候选维度列出直接依据、换算方法、反证和限制。

## 阈值与敏感区

`go` 和 `watch` 阈值应由用户风险偏好、类目分布和资金约束共同确定。若没有被确认的阈值，只输出 `rank_only`。

为每个阈值设置 `boundary_margin`。得分距离任一阈值不超过该值时，标记 `manual_review`；不要把相邻整数分包装成两类本质不同的机会。

## 并列与精度

- 总分四舍五入为整数供展示，但保留内部高精度用于排序。
- 排名先按决策可行性分组：`go`、`watch/rank_only`、`kill`、`blocked`；硬闸门失败的高分候选不能排在可推进候选之前。
- 并列按配置中的 `tie_breakers` 依次比较维度分。
- 仍相同则并列同名次；不得依赖原输入顺序制造差异。

## 强制披露

每个候选至少显示：

```text
原始证据 -> 变换/锚点 -> 维度分 -> x 权重 -> 贡献
可用权重 / 缺失权重
硬闸门
阈值与敏感区
最终状态与决策上限
```

如果两次独立核算不一致，以停止交付并排查证据、配置或公式为正确行为。
