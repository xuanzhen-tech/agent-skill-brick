# 社媒渠道适配方法

## 1. 事实核心与表达外壳

将内容分成：

- **事实核心**：产品事实、限定、价格和政策边界；
- **表达外壳**：钩子、顺序、语气、格式、CTA 和视觉。

适配可以重做外壳，但不能扩大事实核心。

### 正例

长文中的有条件产品优势，在短视频里用演示 + 简短字幕呈现，同时保留适用条件。

### 反例

因为字符不足，删除“在指定条件下”而保留绝对功效。

## 2. 渠道重构问题

每个渠道都应重新回答：

- 用户为何停留；
- 哪个信息必须先出现；
- 证明适合文字、图像、动作还是声音；
- CTA 对应什么下一步；
- 哪些规则影响格式和披露；
- 哪些细节必须移到落地页或后续内容。

## 3. TikTok 公开观察的用途

可以观察：

- 常见视频结构和节奏；
- 演示、口播或字幕的使用；
- 公开主题和表现形式；
- Creator/视频的可见样本。

不能据此确认：

- 平台当前规则；
- 完整热门样本；
- 账号身份或商业权利；
- 互动真实性；
- 转化或效果。

## 4. Locale 适配

本地化应处理单位、币种、日期、文化语气和 CTA，但不改变产品事实或政策含义。直译不自然时可以重写句法，必须回看原始核心声明。

## 5. 短格式的声明选择

当格式无法容纳完整限定时，优先：

1. 选择更窄且可完整表达的事实；
2. 用视觉证明替代冗长描述；
3. 引导到更完整的受控内容；
4. 放弃该声明。

不能通过省略限定制造更强主张。

## 6. 适配差异

差异记录应面向审核者，说明“为什么这样改”：

- 为了渠道注意力结构而重排；
- 为了 locale 而改写；
- 因规则或长度删除；
- 因素材不足阻塞；
- 因声明风险收窄；
- 因促销依据到期移除。
