# 仓库退货处置判断方法

## 1. 先闭合身份与数量

逐单位或批次记录退货/RMA、SKU、可选序列号、当前仓库/库位、保管人和确认时间。

```text
收到数量 = 已检数量 + 未检数量 + 已确认的其他去向数量
```

单位必须一致；抽检数量和全批数量分开。数量不闭合时不得扩大处置范围。

## 2. 实物状态证据

状态判断必须能定位到当前单位或批次的检验人、方法、时间和结果。可用范围由证据决定：

- 单件可定位检验，只支持对应单位；
- 全批按明确规则检验，只支持该批次；
- 抽样只直接支持样本，能否外推由合格责任方决定；
- 无可定位材料的声明只能作为背景；
- 商品页、评论或历史批次问题不能替代当前实物状态。

## 3. 所有权、决策权和批准分开

先确认资产所有者、保管责任人、处分决策权人、是否存在争议和适用时点，再确认有权人是否批准具体候选。

批准必须覆盖同一单位/批次、数量和条件。审批人存在但权限范围未知，不算批准。

## 4. 合规约束不能被人工批准覆盖

涉及跨境退运、海关、税费、清关、危险品、销毁或其它受约束事项时，引用第 09 专家或合格专业责任方带日期、辖区、范围和限制的正式结论。

人工批准不能替代或推翻适用合规约束。不可逆候选在合规要求未知、冲突或过期时必须暂缓。

## 5. 按可逆性排序

- 可逆：有清楚撤回路径、截止点和影响。
- 有条件可逆：条件、成本/影响来源、截止点和批准均明确。
- 不可逆：身份、数量、所有权、状态、地点、价值、合规和明确人工批准全部闭合后，才可交给人工执行。

候选名称本身不能决定可逆性，必须结合本批次具体条件。

## 6. 回收价值

价值材料至少说明金额或区间、币种、单件/整批口径、毛额/净额、估值时点、有效期、包含/排除项和责任方。

未知价值保持未知，不填零。本 Skill 不重建第 14 专家的价值模型。

## 7. 顺序判断

对每个候选依次核对：

1. 用户是否允许考虑该处置；
2. 身份与数量是否闭合；
3. 当前状态证据是否足够；
4. 所有权、决策权和地点是否明确；
5. 可逆性、撤回点和错误影响是否明确；
6. 合规约束是否已处理；
7. 价值材料是否足以比较；
8. 有权人是否批准同一范围。

任一强制问题无法回答时，只能保留候选和补证计划，不得写成已批准执行。

## 8. 工具边界

本方法不调用 SIF、SellerSprite、Sorftime。任何外部商品、销量、评论或市场信号都不能证明退货实物状态、数量、所有权、位置、可逆性、价值、合规约束或批准。
